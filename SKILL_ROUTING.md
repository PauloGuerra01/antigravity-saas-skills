Skill Routing Guide

Use this guide to decide which skill category to consult before implementing a solution.

Backend

For tasks involving:
	•	API endpoints
	•	database access
	•	services or repositories
	•	background jobs
	•	authentication and authorization
	•	caching or webhooks

Consult: skills/backend/

Frontend

For tasks involving:
	•	UI components
	•	client state management
	•	API calls from the browser
	•	frontend architecture

Consult: skills/frontend/

DevOps

For tasks involving:
	•	deployment
	•	CI/CD pipelines
	•	containers
	•	monitoring
	•	backups
	•	environment configuration

Consult: skills/devops/

Quality

For tasks involving:
	•	automated testing
	•	code reviews
	•	static analysis
	•	performance testing
	•	security validation

Consult: skills/quality/

Product

For tasks involving:
	•	feature definition
	•	product requirements
	•	SaaS pricing or monetization
	•	feature validation

Consult: skills/product/

Mandatory Process

Before implementing any code:
	1.	Identify the system layer (backend, frontend, devops, quality, product).
	2.	Navigate to the corresponding skill category.
	3.	Read the relevant SKILL.md.
	4.	Follow the architectural rules described there.
:::
