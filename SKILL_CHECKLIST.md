Skill Implementation Checklist

Before implementing any feature, confirm the following:
	•	I identified the system layer involved in this task.
	•	I checked whether a relevant skill exists.
	•	I read the SKILL.md associated with that skill.
	•	I understood the architectural rules defined in the skill.
	•	My implementation follows the skill constraints.

If any item above is not satisfied, the implementation should be reconsidered.
:::
